# DevQuest

A Gamified Learning Platform that helps college students become industry-ready software developers through structured roadmaps, missions, mentorship, leaderboards, and AI assistance.

## Features

- Learning Roadmaps
- XP & Level System
- Missions & Challenges
- Peer Mentorship
- Real-Time Chat
- AI Assistant
- Leaderboards

## Tech Stack

Frontend:
- Next.js
- Tailwind CSS

Backend:
- Node.js
- Express.js

Database:
- MongoDB

Real-Time:
- Socket.io

Authentication:
- Clerk

AI:
- OpenAI API
